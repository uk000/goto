# Types Package

This package defines common data types and structures used throughout the application.

## REST APIs

This package does not expose REST APIs. It provides type definitions and data structures used by other packages.

## Delay (`delay.go`)

`types.Delay` models a delay range with an optional use count; it backs delays in client targets, jobs, payloads (stream delay) and gRPC. All its methods are safe for concurrent use (the lock is held only for bookkeeping, never while sleeping); a `Delay` must not be copied by value, use `Clone()`.

JSON/YAML shape (`Delay`):

|Field|Type|Default|Meaning|
|---|---|---|---|
| min | duration string (`"100ms"`) | | Lower bound |
| max | duration string | | Upper bound. A delay without min and max is "no delay" |
| count | int | `-1` | Number of times the delay applies; `0` and values below `-1` become `-1` (unlimited) |

Duration range syntax (`ParseDurationRange`, used by the delay APIs such as `/response/delay/set/{delay}`):

```
<low>                 e.g. 500ms
<low>-<high>          e.g. 100ms-2s    (bounds are reordered if given high-low)
<low>[-<high>]:<count> e.g. 1s-3s:5    (count <= 0 or not a number: unlimited)
```
A bound that is not a Go duration makes the whole range invalid (`ok=false`; APIs answer `400`). `NewDelay(min, max, count)` returns `nil` if `max <= 0` or `count < -1`; `ParseDelay` combines both.

Methods: `Compute()` (peek the next delay), `Claim()` (take it and count it, without sleeping), `Apply()` (claim and sleep), `ComputeAndApply(cb)`, `Block()` (apply in the background, deliver on a channel), `IsNonZero()`, `IsLargerThan()`, `Prepare()` (normalise), `Clone()`. The use count is decremented when a delay is claimed, so concurrent callers do not all take the last count.

`types.Duration` wraps `time.Duration` with JSON/YAML (un)marshalling as a duration string.

## Random helpers (`random.go`)

* `RandomDuration(min, max, fallback...)`: `min` plus a random amount below `max-min` (so in `[min, max)`; `min` itself when `max <= min`); returns the fallback (or 0) only when both `min` and `max` are 0. (The response-delay middleware additionally answers a range narrower than 1ms with its low end.)
* `RandomFrom([]int)`, `Random(max)`, `Random64(max)`: random picks; `max <= 0` is guarded.
* `GenerateRandomPayload(size, prefix...)`: a random payload of `size` bytes, optionally starting with a prefix (the stream API uses the listener label). Generated byte by byte under a mutex: slow for large sizes (about 0.2s per 20 MB) and `size` is not capped here, so callers must cap user-supplied sizes.
* `GenerateRandomString(size)`, `ID()`.

## Other types

`Headers`/`HeadersConfig` (add/remove/forward header sets with `Merge`/`Union`/`Clone`), `ListArg` (repeatable flag), `Pair`/`Triple`/`StringPair`, `RawBytes`.
